# Cocket Nova CH552G-Development-Board

Explora las características de la placa de desarrollo Cocket Nova, impulsada por el microcontrolador CH552G. Esta versátil placa es ideal para proyectos embebidos, ofreciendo compatibilidad con protoboards estándar y programación mediante USB Tipo C. Incluye un LED Neopixel integrado, encabezados adicionales para Neopixels y conectores que soportan los protocolos QWIIC y STEMMA QT.

## Características Principales 📝

- **Microcontrolador**: CH552 con núcleo e8051.
- **Programación USB**: Transceptor USB integrado para programación mediante USB Tipo C.
- **Opciones de Voltaje**: Opera a 5V o 3.3V con voltaje seleccionable.
- **LEDs**: Neopixel en el pin 3.3 y LED en el pin 3.4.
- **Conectividad**: Dos conectores JST que soportan los protocolos QWIIC y STEMMA QT.
- **Compatibilidad con Protoboard**: Se adapta a protoboards estándar.

## Especificaciones Técnicas 🚀

- **Memoria**: 16 KB ROM, 128 bytes flash, 256 bytes RAM.
- **Periféricos**: PWM, ADC, detección táctil, GPIOs, interrupciones, temporizador Watch Dog.
- **USB**: Soporte USB 2.0 con velocidad de datos de 12 Mbps.
- **Comunicación**: UART, SPI y I2C por software.
- **Energía**: Opera dentro del rango de 2.8V a 3.5V.
- **Conectores**: Conectores JST para alimentación y comunicación.
