# Cocket Nova CH552G-Development-Board

Explore the features of the Cocket Nova development board, powered by the CH552G microcontroller. This versatile board is ideal for embedded projects, offering compatibility with standard breadboards and USB Type C programming. It includes a built-in Neopixel LED, additional headers for Neopixels, and connectors supporting QWIIC and STEMMA QT protocols.

## Key Features 📝

- **Microcontroller**: CH552 with e8051 core.
- **USB Programming**: Built-in USB transceiver for programming via USB Type C.
- **Voltage Options**: Operates on 5V or 3.3V with selectable voltage.
- **LEDs**: Neopixel on pin 3.3 and LED on pin 3.4.
- **Connectivity**: Two JST connectors supporting QWIIC and STEMMA QT protocols.
- **Breadboard Compatibility**: Fits standard breadboards.

## Technical Specifications 🚀

- **Memory**: 16 KB ROM, 128 bytes flash, 256 bytes RAM.
- **Peripherals**: PWM, ADC, touch detection, GPIOs, interrupts, Watch Dog timer.
- **USB**: USB 2.0 support with 12 Mbps data rate.
- **Communication**: UART, SPI, and soft I2C.
- **Energy**: Operates within 2.8V to 3.5V range.
- **Connectors**: JST connectors for power and communication.
